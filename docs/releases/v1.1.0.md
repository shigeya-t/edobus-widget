# 江戸バス接近情報 1.1.0

中央区コミュニティバス「江戸バス」の到着見込みを、メニューバーとデスクトップのウィジェットに出しておく macOS アプリです。
今回から、自分でビルドしなくても DMG から入れられるようになりました。

## インストール

1. DMG を開き、**EdoBusWidget** を **Applications** フォルダへドラッグします。
2. アプリケーションフォルダから **EdoBusWidget** を起動します。Dock には出ず、メニューバーにバスのアイコンと次のバスまでの分数が出ます。
3. デスクトップを右クリック →「ウィジェットを編集」→ **江戸バス接近情報** を選んで配置します。
4. 置いたウィジェットを右クリック →「ウィジェットを編集」で、路線（北循環 / 南循環）とバス停を選びます。
5. 常用するなら、システム設定 →「一般」→「ログイン項目」に登録してください。到着見込みはアプリが取得してウィジェットに渡します。

**動作条件:** macOS 14 以降、インターネット接続。

## できること

- **到着見込みのカウントダウン** — 時刻表の定刻ではなく、バスロケーションシステムの位置情報にもとづく見込みを表示します。
- **北循環 33 停留所 / 南循環 44 停留所** — ウィジェットごとにバス停を選べます。
- **平日 / 土曜 / 日祝のダイヤを自動判定** — 祝日は holidays-jp を参照します。
- **ウィジェット（小・中）とメニューバー表示** — 一時停止・手動更新にも対応。

## 最近の主な変更

- macOS 27.2.1 で、ウィジェット設定の路線・バス停を選んでも反映されない問題を直しました（検索つきリストで選ぶ形に変更）
- 遅れている次のバスにも定刻を併記するようにしました
- 通信のディスクキャッシュをやめ、常駐アプリが強制終了されるのを防ぎました
- 小ウィジェットでも定刻を3件表示し、見出しにダイヤ種別を出すようにしました
- 他のウィジェットと AppIntent の型名が衝突して更新が止まる問題を直しました
- 配布に向けて hardened runtime を有効にしました

## ご注意

- **以前に自分でビルドして入れていた場合は、先にそちらを削除してください**（`~/Applications/EdoBusWidget.app` など）。同じアプリが 2 か所にあると、ウィジェットがプレースホルダのままになることがあります。配布版は自前ビルドと App Group が異なるため、選んでいたバス停は引き継がれません。置いてあったウィジェットは削除して、追加し直してください。
- **非公式のデータ取得です。** 中央区が公開している BusGO! バスロケーションシステムが内部で使うエンドポイントを利用しています。サイト側の変更で突然取れなくなることがあります。
- 詳しい使い方は [README](https://github.com/shigeya-t/edobus-widget#readme) を参照してください。

## ウィジェットが真っ白・黒い枠のままのとき

同じアプリが Mac 上に複数あると、macOS がウィジェットを見つけられず描画されないことがあります。

1. **EdoBusWidget.app** を 1 つだけ残し、ほかは削除してゴミ箱も空にします（`/Applications` と `~/Applications` の両方に置いていないか、自分でビルドしたものが残っていないかを確認）。
2. DMG をマウントしたままなら取り出します。
3. ターミナルで次を実行して、ウィジェットの表示を再起動します。

   ```sh
   killall NotificationCenter
   ```

4. それでも直らなければ、ウィジェットをいったん外して置き直してください。
